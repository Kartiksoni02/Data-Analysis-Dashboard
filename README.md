# Data-Analysis-Dashboard

📱 Mobile Phone Market Analysis
Tech Stack: Tableau | Date: November 2024

Overview
This project presents a comprehensive data visualization of the mobile phone market using Tableau. The goal is to uncover patterns and trends that can guide consumer and business decisions.

🔍 Key Features
Interactive Dashboard to explore smartphone trends

Analysis of:

Customer ratings

Pricing

Storage capacity

Brand performance

Visualizations include:

Bar charts

Tree maps

Scatter plots

Provides actionable insights for better decision-making

📊 Outcome
By converting raw data into intuitive visuals, this dashboard enables users to:

Compare smartphones across key metrics

Identify top-performing brands

Make informed purchase or strategy decisions

🧰 Tools Used
Tableau (for visualization and dashboard design)

Excel/CSV (data preprocessing)
